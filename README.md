🏥 **Hospital Patient Analytics & Treatment Cost Dashboard**

📌 **Project Overview**

Cleaned and analyzed hospital patient data using Microsoft Excel to develop an interactive dashboard highlighting patient demographics, treatment costs, departmental performance, diagnosis distribution, and insurance coverage. The dashboard provides meaningful insights to support data-driven healthcare analysis and operational decision-making.

🛠️ **Tools & Technologies**

• Microsoft Excel — Data Cleaning, Data Analysis, PivotTables, PivotCharts, and Dashboard Development.

• Excel Slicers — Interactive Data Filtering and Exploration.

• Data Visualization — KPI Cards, Pie Charts, Doughnut Charts, Bar Charts, and Line Charts.

⚙️ **Key Activities**

• Cleaned and prepared hospital patient data for accurate analysis.

• Analyzed patient demographics, treatment costs, diagnoses, insurance coverage, and departmental performance.

• Developed an interactive dashboard featuring key performance indicators (KPIs) and visualizations.

• Implemented interactive slicers to explore data by department, gender, diagnosis, insurance status, and city.

📊 **Dashboard Highlights**

• **Patient Demographics:** Visualized gender distribution and average patient age.

• **Departmental Analysis:** Compared patient counts and average treatment costs across hospital departments.

• **Diagnosis Analysis:** Examined patient distribution across different medical diagnoses.

• **Insurance Analysis:** Evaluated the distribution of patients by insurance status.

• **Geographical Analysis:** Compared patient counts across different cities.

• **KPI Monitoring:** Presented total patients, total treatment cost, average treatment cost, average patient age, and insurance coverage.

💡 **Business Value**

Transformed raw hospital data into an interactive visual dashboard, enabling efficient analysis of patient demographics, treatment expenses, insurance coverage, and departmental activity. The dashboard supports healthcare cost monitoring, patient analysis, and informed operational decision-making.

✅ **Project Outcome**

Developed an interactive Excel dashboard that consolidates key hospital performance metrics and transforms patient data into meaningful visual insights for effective healthcare data analysis.
